## 从真实格式发现并修复的问题

原适配器把数组全部视为不可处理，所以只识别了一对可压缩记录。
现支持由纯 `input_text` 组成的数组；保留时返回原对象，截短时保持数组
传输形式与顶层元数据。含图片或未知块字段的结果仍保留原样。

另外补回了长 custom-tool 输入的截短标记：核心生成的 `note` 现在会
写回自由文本输入，避免只有省略号而没有明确来源标记。
