## 默认别名与服务回报

实际请求默认是 `jev-latest`，没有固定 `jev-1.13.0`。官方
[`GET /v1/models`](https://api.typesafe.ai/docs) 为当前账号列出
`jev-latest`、`jev-preview` 两个名字。两者的简单请求和完整对话请求
都回报 `model: jev-1.13.0`。

这只能证明本次服务返回的标识，不能独立判断其实际权重是否为 1.14，
也不能据此认定 1.14 未发布。生产继续用 `jev-latest`，Preview 作为
显式实验；不把响应版本写回请求配置。服务升级别名后，客户端随之使用。

Preview 比 Latest 改变了 3 个动作，不证明 Preview 的保留质量更好。

JeV 更激进；混合路径保留更多完整工具输出，但该配置本轮没有比 OpenAI

Codex 仲裁。`.local-eval/current-chat/` 保存各阶段答案、模型列表、别名

丢失。保持 Noul、现有阈值和显式仲裁选择，不凭本次压缩率更改默认策略。
